# P1 — Landing Governance Runtime Surface

Adds a public Runtime Surface immediately after the landing hero. It communicates `DISCOVER → ASSESS → GOVERN → ENFORCE → EVIDENCE → AUDIT` as one operational governance plane.

The surface is explicitly labelled as an example and does not claim tenant-specific live metrics for anonymous visitors.

Validation is delegated to CI because this GitHub connector can modify and inspect repository sources but cannot execute the repository's Node/Vite toolchain.

Do not merge automatically; review CI and the rendered landing page first.
