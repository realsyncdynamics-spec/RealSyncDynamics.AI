# M10–M19 — Planungsdokumente

**Für alle gilt:** ausdrücklich **NICHT zur eigenständigen Umsetzung freigegeben.** Erster Schritt
je Meilenstein ist ein Planungs-Draft-PR (Spec, keine Code-Änderung). Freigabe je Meilenstein einzeln.
„Wiederverwendung“ nennt nur Pfade, die im Repo existieren (Stand main, 2026-10-29).

## M10 Autonomous Agent Operations
- **Ziel:** Agenten-Läufe planen, starten, beobachten, mit Freigabe-Schleife (Decision Inbox).
- **DoD:** Lauf-Status je Agent aus belegten Quellen; jede Aktion mit Freigabe + Audit-Eintrag; Kill-Switch fail-closed.
- **Abh.:** M1-a/b, M2–M4, M7 (Klärung).
- **Wiederverwendung:** `apps/agent-runtime/`, `src/features/command-center/`, `agent_registry_v`, `platform/builder_orchestrator/` (Budget, Audit-Log).
- **Risiken/Freigaben:** autonome Aktionen mit Außenwirkung; Live-Migration; VPS-Deploy (`deploy-agent-runtime-vps.yml`).

## M11 CEO Executive Cockpit
- **Ziel:** Eine Seite mit KPIs, Freigaben, Risiken für Dominik.
- **DoD:** nur belegte Kennzahlen (kein Demo-Wert als Live-Wert); Quelle je Kachel sichtbar.
- **Abh.:** M10, M16. **Wiederverwendung:** `src/features/governance` (Cockpit-Bausteine), `src/features/finance`.
- **Risiken:** Fabrikationsgefahr (`npm run check:fabrication`), Super-Admin-Rechte.

## M12 SEO & Growth Intelligence
- **Ziel:** SEO-/Growth-Signale bündeln, Empfehlungen ohne Auto-Publish.
- **DoD:** Metriken aus `calculate-seo-metrics`/`seo-dashboard-data`; E2E grün.
- **Abh.:** M10. **Wiederverwendung:** `src/features/seo-marketing-dashboard`, `e2e/seo-*.spec.ts`, `docs/growth-agent-stack.md`.
- **Risiken:** keine erfundenen Rankings; externe SEO-APIs kostenpflichtig → Quote + Go.

## M13 Customer & Sales Operations
- **Ziel:** Leads, Kundenkontakte, Übergaben (AI Receptionist) zusammenführen.
- **DoD:** Lead-Pipeline mandantengetrennt, RLS-getestet; keine CTAs „Demo/Call/Sales“ öffentlich (`AGENTS.md`).
- **Abh.:** M10, M15. **Wiederverwendung:** Function `sales-lead`, `docs/sales/`, `src/features/admin`.
- **Risiken:** personenbezogene Daten (DSGVO), E-Mail-Versand nur mit Freigabe.

## M14 AI Creative & 3D Production Studio  *(Geschäftsbereich Studio)*
- **Ziel:** Studio-Produktionsweg Brief → Design → Assets → Build → Preview.
- **DoD:** Pilotprojekt in privatem Repo mit Herkunftsnachweis (`.ai/provenance/`), Lighthouse-Budget, reduced-motion-Fallback.
- **Abh.:** Entscheidung C, **#2070 (blockiert)**, Vorschau-Worker-Einrichtung. **Wiederverwendung:** `packages/siteos-core`, `src/features/siteos/editor` (Puck), `workers/siteos-preview`, R3F-Szenen in `src/components/visual`, Higgsfield-/Figma-MCP.
- **Risiken:** Credits (Higgsfield), Spline-Abo, Kundendaten nie ins öffentliche Repo.

## M15 Central Bot Configuration Manager
- **Ziel:** Soll-Konfiguration aller Bots/Agenten zentral, versioniert, mit Freigabe.
- **DoD:** `SOLL_CONFIG` aus M1-b in persistente, auditierte Konfiguration überführt; Status bleibt UNBEKANNT ohne Quelle.
- **Abh.:** M1-a/b, M10. **Wiederverwendung:** `src/features/bots`, Functions `bot-chat`/`bot-voice-*`, `agent_profiles`.
- **Risiken:** Grok-Bots haben keine Admin-API im Repo (#2071) → keine erfundene Steuerung.

## M16 Financial & Pricing Intelligence (read-only Stripe)
- **Ziel:** Umsatz-/Abo-Sicht lesend.
- **DoD:** nur lesende Stripe-Zugriffe; keine Schreib-Scopes; Studio-Umsätze getrennt.
- **Abh.:** M10. **Wiederverwendung:** `sync-stripe-metrics`, `src/features/finance`, `npm run stripe:diff` (nur Diff, nie `stripe:sync`).
- **Risiken:** Preis-/Stripe-Änderungen absolut verboten ohne Go; Restricted-Key-Freigabe nötig.

## M17 Multichannel Content Operations
- **Ziel:** Inhalte planen und kanalübergreifend vorbereiten, Veröffentlichung nur nach Freigabe.
- **DoD:** Entwurf → Freigabe → Publish-Log; kein Auto-Post.
- **Abh.:** M10, M12. **Wiederverwendung:** `src/core/social-orchestrator`, Functions `social-publisher-worker`, `social-orchestrator-persistence`.
- **Risiken:** öffentliche Posts = Außenwirkung, Claims-Regeln (`check:landing-claims`).

## M18 Proactive Infrastructure & Governance
- **Ziel:** Drift, Ausfälle, Fristen proaktiv melden.
- **DoD:** bestehende Drift-Workflows + Monitoring in eine Meldungsliste mit Verantwortlichem.
- **Abh.:** M10, M7. **Wiederverwendung:** `.github/workflows/*-drift*.yml`, `governance-monitoring-scheduler`, `governance-deadline-monitor`, `governance-incidents`, `npm run check:*`.
- **Risiken:** automatische Fixes nur als Draft-PR.

## M19 Enterprise Readiness
- **Ziel:** SSO, SCIM, Identity, Nachweise für Enterprise-Kunden.
- **DoD:** ADR 0004/0007/0008 umgesetzt oder bewusst verschoben; Sicherheitsnachweise verlinkt.
- **Abh.:** M18. **Wiederverwendung:** `docs/adr/0004-enterprise-identity.md`, `0007-sso-strategy.md`, `0008-scim-provisioning.md`, `docs/architecture/enterprise-identity-p0a-mfa-plan.md`.
- **Risiken:** Enterprise-Preise nur aus `shared/pricing.ts`; IdP-Kosten.
