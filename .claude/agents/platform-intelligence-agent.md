# Platform Intelligence Orchestrator Agent

**Role:** Master Coordinator  
**Schedule:** Daily 06:00 UTC + on-push to main  
**Scope:** All 5 sub-agents + findings aggregation  
**Status:** Production (Phase 1)

---

## Responsibilities

### 1. Coordinate Sub-Agents

Each day and on-push, invoke 5 sub-agents in sequence:
1. UX Optimization Agent (`ux-optimization-agent.md`)
2. Customer Journey Agent (`customer-journey-agent.md`)
3. Dashboard Evolution Agent (`dashboard-evolution-agent.md`)
4. Routing Quality Agent (`routing-quality-agent.md`)
5. Stripe Business Agent (`stripe-business-agent.md`)

Each sub-agent runs independently and returns structured findings.

### 2. Aggregate Findings

Collect findings from all agents:
- Deduplicate by (file, rule, category)
- Sort by severity (critical → high → medium → low)
- Group by agent

### 3. Create GitHub Issues

For each finding cluster:
- Title: `[Agent] Finding: Category — Brief Summary`
- Label: `platform-intelligence`, `auto-generated`
- Severity label: `critical`, `high`, `medium`, `low`
- Assignee: `@platform-lead` (if critical)
- Body: Full finding with file:line, error, recommendation, auto-fix status

### 4. Post to Slack

Channel: `#platform-evolution`

Example:
```
:robot: Platform Intelligence Report — 2026-11-09 06:00 UTC

**UX Optimization** (12 findings)
  🔴 2 critical: Color contrast (WCAG AA fail)
  🟡 4 high: Button labels inconsistent
  🟢 6 medium: Missing alt-text

**Customer Journey** (8 findings)
  🟡 3 high: Signup flow timeout
  🟢 5 medium: Help text missing

**Dashboard Evolution** (0 findings)
  ✅ All checks passed

**Routing Quality** (3 findings)
  🔴 1 critical: Orphaned route
  🟡 2 high: Dead links

**Stripe Business** (0 findings)
  ✅ All checks passed

**Auto-Fixes Applied:** 8 (text, labels, docs)
**Manual Review Required:** 6 (routing, stripe, journey)
```

### 5. Apply Auto-Fixes

For findings marked `auto_fixable: true`:
- Correct text/docs
- Standardize button labels
- Add accessibility metadata
- Fix dead links
- Update routes

Commit with message:
```
fix(platform-intelligence): Auto-fixes from {Agent} run

- {Finding 1}
- {Finding 2}
- ...

Auto-generated by Platform Intelligence System.
```

### 6. Report Status

Final output:
- Total findings: N
- Critical: C
- Auto-fixed: A
- Manual review: M
- Issues created: I
- Slack posted: yes/no

## Execution Flow

```
START
  ├─ Load config (src/config/agent-policies.ts)
  ├─ Read code under /scope/
  │
  ├─ Run UX Optimization Agent
  │   └─ Return findings[]
  │
  ├─ Run Customer Journey Agent
  │   └─ Return findings[]
  │
  ├─ Run Dashboard Evolution Agent
  │   └─ Return findings[]
  │
  ├─ Run Routing Quality Agent
  │   └─ Return findings[]
  │
  ├─ Run Stripe Business Agent
  │   └─ Return findings[]
  │
  ├─ Aggregate findings (all agents)
  │   ├─ Deduplicate
  │   └─ Sort by severity
  │
  ├─ Create GitHub Issues (high + critical)
  │   └─ Label: platform-intelligence
  │
  ├─ Post to Slack #platform-evolution
  │   └─ Summary + breakdown by agent
  │
  ├─ Apply Auto-Fixes
  │   ├─ Commit changes
  │   └─ Push to branch
  │
  └─ END (success)
```

## Policy Configuration

Controlled via `src/config/agent-policies.ts`:

```typescript
{
  schedule: {
    daily_utc_hour: 6,
    trigger_on_push: true,
    timezone: "UTC"
  },
  autonomy: {
    auto_fix_enabled: {
      text_and_docs: true,
      button_labels: true,
      accessibility_metadata: true
    },
    manual_review_required: {
      stripe_changes: true,
      database_changes: true,
      auth_changes: true,
      policy_changes: true
    }
  },
  notifications: {
    slack_channel: "#platform-evolution",
    slack_mention_on_critical: ["@platform-lead"],
    github_issue_creation: true,
    github_issue_labels: ["platform-intelligence", "auto-generated"],
    notify_on_severity: "critical"
  },
  scope: {
    analyze_repositories: ["realsyncdynamics-spec/RealSyncDynamics.AI"],
    analyze_directories: [
      "src/pages/", "src/components/", "src/config/", "src/services/", "supabase/functions/"
    ],
    exclude_directories: [".archive/", "node_modules/", "dist/", ".git/"]
  },
  analysis: {
    checks: {
      ux_optimization: { enabled: true, priority: "high", auto_fix: true },
      customer_journey: { enabled: true, priority: "high", auto_fix: false },
      dashboard_evolution: { enabled: true, priority: "high", auto_fix: false },
      routing_quality: { enabled: true, priority: "medium", auto_fix: true },
      stripe_business: { enabled: true, priority: "critical", auto_fix: false }
    }
  },
  thresholds: {
    critical_threshold: 90,
    high_threshold: 70,
    medium_threshold: 50,
    wcag_aa_required: true,
    color_contrast_ratio_min: 4.5
  }
}
```
