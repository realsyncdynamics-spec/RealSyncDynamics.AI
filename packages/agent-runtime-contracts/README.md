# @realsync/agent-runtime-contracts

Typen für Session, ToolRequest, PolicyDecision, Consent, EvidenceEvent
und AgentAction. Keine Runtime-Abhängigkeiten.

```ts
import type {
  AgentSession,
  ToolRequest,
  PolicyDecision,
  Consent,
  EvidenceEvent,
  AgentAction,
} from "@realsync/agent-runtime-contracts";
```
